# Smart-Home-Automation-System

This project is a Smart Home Automation system developed using Cisco Packet Tracer and IoT concepts. It allows users to remotely control and monitor home devices such as lights, fans, and security systems. The system uses sensors to detect environmental conditions like temperature, motion, and smoke, providing automation and improving safety, comfort, and energy efficiency.

Key Highlights:

Remote control of home devices , 
Real-time sensor monitoring , 
Automated system based on conditions , 
Improved home security , 
Energy-efficient solution , 
User-friendly interface 

Technologies Used:

IoT (Internet of Things) – connects smart devices , 
Cisco Packet Tracer – for simulation of smart home network , 
Wireless Technology (Wi-Fi) – communication between devices , 
Sensors – motion sensor, temperature sensor, smoke detector , 
Microcontrollers – like Arduino (in real systems) , 
Cloud Computing – for remote access and data storage , 
Mobile/Web Application – for user control 

Network Components:

Home Gateway (Router) – connects all devices to the internet , 
Smart Devices – smart lights, fans, doors , 
Sensors – detect environmental changes , 
Server/Cloud – stores data and processes commands , 
User Device – smartphone or computer , 
Wireless Access Point – enables Wi-Fi communication
