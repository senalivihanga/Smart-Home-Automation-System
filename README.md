# Smart-Home-Automation-System
Overview:

This project is a Smart Home Automation system developed using Cisco Packet Tracer and IoT concepts. It allows users to remotely control and monitor home devices such as lights, fans, and security systems. The system uses sensors to detect environmental conditions like temperature, motion, and smoke, providing automation and improving safety, comfort, and energy efficiency.

Features:

Remote control of smart devices
Real-time monitoring using sensors
Automated responses based on conditions
Improved home security
Energy-efficient system
User-friendly interface

Technologies Used:

Cisco Packet Tracer
IoT (Internet of Things)
Wireless Networking (Wi-Fi)
Sensors (Motion, Temperature, Smoke)

System Architecture:

The system is based on a 3-layer architecture:
Device Layer – Sensors and smart devices collect data
Network Layer – Wi-Fi network connects devices
Application Layer – User interface for monitoring and control

Usage:

Open the project in Cisco Packet Tracer
Start the simulation mode
Interact with smart devices (turn ON/OFF)
Monitor sensor outputs (temperature, motion, smoke)
Observe automated responses
